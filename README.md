# Fashion-Demand-Forecasting

## Overview

This project builds a demand forecasting framework for fashion retail using historical transaction data from the H&M Personalized Fashion Recommendations dataset (Kaggle).

The objective is to forecast weekly unit demand at the product-category level to support inventory allocation and seasonal merchandising decisions.

---

## Business Problem

Fashion retailers face high demand uncertainty due to:

- Seasonality
- Trend volatility
- Large SKU variety
- Rapid product lifecycle turnover

Inaccurate forecasts lead to:
- Overstock in slow-moving items
- Stockouts in high-demand products
- Margin erosion from markdowns

This project aims to translate transactional data into actionable demand forecasts that improve inventory planning decisions.

---

## Analytical Approach

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Weekly demand aggregation
- Feature engineering
- Time-series modeling (planned: SARIMA / Prophet)
- Model evaluation and comparison
